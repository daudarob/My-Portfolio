# Dauda Abdulai: Portfolio

A static portfolio site (HTML, CSS, JavaScript). No build step or dependencies.

## Run it
Open `index.html` in a browser, or serve the folder:

    python3 -m http.server 8000   # then visit http://localhost:8000

## Publish it for free
- **GitHub Pages:** push this folder to a repo named `daudarob.github.io`, then enable Pages in Settings.
- **Netlify / Vercel:** drag and drop the folder.

## Edit your content
- Text, projects, experience and certificates: `index.html`
- Colors and fonts: the `:root` variables at the top of `css/styles.css`
- Photo: replace `assets/photo.jpg`
- Resume: replace `assets/Dauda_Abdulai_Resume.pdf` (keep the file name or update the link)
- Project links: replace the GitHub profile links in each project card with the exact repo URL, and add a live demo link where you have one.
